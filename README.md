🗂️ WhereIsWhat – Project Planning, Visual Boards & Documentation Inside Unreal

📌 Plan, document, organize, and connect your Unreal Engine project — directly inside the Editor.

WhereIsWhat is an Unreal Engine plugin for creating visual boards, project documentation, plans, references, and bookmarks without constantly switching between Unreal Engine and external tools.

Keep your project knowledge close to the things it describes — with direct links to assets, folders, actors, level locations, Blueprint graphs, functions, macros, and nodes.

🔥 Why WhereIsWhat?

Working on an Unreal Engine project often means spreading information across:

external documentation
screenshots
notes
task lists
reference boards
project management tools
Blueprint comments
messages and chat history

And when documentation refers to something inside Unreal Engine, you often still need to manually find that asset, Blueprint, actor, level location, or graph.

WhereIsWhat connects your project documentation directly with Unreal Engine content.

Instead of writing:

“Check the interaction logic in BP_Player → Interact → ValidateTarget”

you can create a board node that links directly to that Blueprint graph or node.

roadmaps

Keep planning close to the Unreal Engine project instead of maintaining disconnected documents.

🎮 Game Design

Document:

gameplay mechanics

references

Boards can link directly to the Unreal Engine content implementing those systems.

Jump directly from documentation to relevant actors, assets, or places in the level.

Document technical systems with direct links to their implementation:

Blueprint references

debugging notes
technical TODOs
🔷 Blueprint Bookmarks

WhereIsWhat can reference locations inside Blueprints, not only Blueprint assets.

Create bookmarks for:

Blueprint graphs
functions
macros
individual nodes

Open a bookmark to quickly return to the relevant Blueprint location.

This makes WhereIsWhat useful for documenting systems where a simple asset link is not enough.

🌍 Level & Actor Bookmarks

Boards can also reference content inside your levels.

Use bookmarks for:

actors
important locations
gameplay areas
level design notes
problem locations
environment references

Instead of describing where something is located, link directly to it.

🔗 Connected Boards

A single board does not need to contain your entire project.

Create smaller boards for individual systems and connect them together.

For example:

Project Overview → Gameplay → Player → Combat → Weapons

or

Roadmap → Version 1.0 → Feature → Implementation Notes

This allows WhereIsWhat to work as a connected visual knowledge base for your Unreal Engine project.
